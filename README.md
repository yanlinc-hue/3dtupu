# DealGraph · 精品投行客户关系图谱

[打开 3dtupu.com](https://3dtupu.com)

围绕客户查看关键人物、机构与项目之间的任职、持股、投融资、顾问、合作及引荐关系。

- 导入结构化关系 JSON，先在浏览器生成规则预览。
- 选择 GPT-4o 分析，用自己的 OpenAI API 密钥并逐次确认上传。
- 按客户中心、关系类型与历史状态浏览网络；导出图谱不含原文。
- 默认展示虚构样例，不包含真实微信数据。

密钥只暂存当前页面，30 分钟或离开页面后清除；运行时通过同域服务器用于本次 OpenAI 请求，不保存到服务器。材料与结果不持久化。浏览器插件仍可能读取页面，请使用可信设备和专用限额密钥。OpenAI 的 `store:false` 不等于零保留。
