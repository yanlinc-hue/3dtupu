# DealGraph · 精品投行客户关系图谱

[打开 3dtupu.com](https://3dtupu.com)

围绕客户查看关键人物、机构与项目之间的任职、持股、投融资、顾问、合作及引荐关系。

- 导入结构化关系 JSON，先在浏览器生成规则预览。
- 点击“连接大模型”：默认 GPT-4o，可选 OpenAI、DeepSeek、通义千问和 Kimi；使用对应服务商密钥并逐次确认上传。
- 按客户中心、关系类型与历史状态浏览网络；导出图谱不含原文。
- 2D / 3D 自由切换，共用关系筛选、搜索、节点/关系详情、中心切换和导出；3D 支持旋转、平移、缩放及键盘操作。
- 默认展示虚构样例，不包含真实微信数据。

密钥只暂存当前页面，30 分钟、离开页面或切换模型后清除；运行时通过同域服务器用于本次所选服务商请求，不保存到服务器。材料与结果不持久化。浏览器插件仍可能读取页面，请使用可信设备和专用限额密钥。各服务商有各自保留政策，OpenAI 的 `store:false` 不等于零保留。国内模型不代表 Cloudflare 中转全链路仅在境内处理。
